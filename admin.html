發佈到網站

方法一：一鍵發佈（推薦）

第一次使用要貼上一次 GitHub 存取權杖，之後這部電腦就會記住，以後按一下就發佈。 權杖只儲存在你自己的瀏覽器，不會上傳到網站；請不要在公用電腦儲存。 產生權杖時，Repository access 選這一個 repository，Permissions 的 Contents 要設為 Read and write。 前往產生權杖 ↗

開啟網站 ↗

方法二：手動複製貼上（不需要權杖）
  1. 按 複製全部內容（或下載 content.js）。
  2. 按 在 GitHub 開啟 content.js，登入後會直接進入編輯畫面。
  3. 在 GitHub 的編輯框內按 Ctrl+A 全選，再 Ctrl+V 貼上。
  4. 按綠色的 Commit changes，等一兩分鐘網站就會更新。
