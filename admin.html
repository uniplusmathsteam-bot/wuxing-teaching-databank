卡片預覽

管理科目

這裡加減的科目，會即時出現在網站首頁的「按科目瀏覽」和內容的科目選單。
改名不會影響已分類的內容，例如把「數學」改成「初中數學」，再新增一個「高中數學」，然後逐項內容改選新科目就可以。
刪除一個仍有內容的科目，那些內容會變成「未分類」，不會被刪走。

發佈到網站

方法一：一鍵發佈（推薦）

第一次使用請先完成導師設定及權限驗證，再貼上自己的 GitHub 存取權杖。 權杖不會上傳到網站；只應在自己的私人電腦選擇記住。 產生權杖時，Repository access 選這一個 repository，Permissions 的 Contents 要設為 Read and write。 查看完整設定指南 →

開啟網站 ↗

緊急後備：手動複製貼上（較容易覆蓋其他人的修改）
  1. 只在一鍵發佈無法使用時採用。先重新整理本頁，確保載入 GitHub 最新內容。
  2. 按 複製全部內容（或下載 content.js）。
  3. 按 在 GitHub 開啟 content.js，登入後會直接進入編輯畫面。
  4. 在 GitHub 的編輯框內按 Ctrl+A 全選，再 Ctrl+V 貼上。
  5. 按綠色的 Commit changes，再到 repository 的 Deployments 確認網站更新完成。
