Teacher instructions

導師設定步驟

共 5 步
  1. 1

    登入自己的 GitHub 帳戶

    每位導師必須使用自己的個人帳戶，並由管理員邀請成為 repository collaborator。不要共用管理員帳戶、密碼或權杖。

    登入 GitHub ↗
  2. 2

    接受協作者邀請

    使用個人帳戶的導師，先接受管理員發出的 repository 邀請。使用 repository 擁有者帳戶可跳過此步。

    查看 Repository 邀請 ↗
  3. 3

    建立自己的存取權杖

    按下面按鈕會預填名稱、90 日期限和 Contents: Read and write。 在 GitHub 頁面再選擇 Only select repositories， 並勾選 wuxing-teaching-databank。

    建立 Fine-grained token ↗ 無法選擇 repository？使用 Classic token ↗

    Classic token 只需保留 public_repo 權限。按 Generate token 後立即複製 github_pat_… 或 ghp_…；離開頁面後 GitHub 不會再次顯示完整權杖。

  4. 4

    貼上並驗證權杖

    驗證會確認目前帳戶已接受邀請，而且具備 Write、Maintain 或 Admin 發佈權限；過程不會修改 repository。

  5. 5

    前往編輯器並發佈

    新增內容、從電腦選擇影片和封面、填寫科目與標籤，再按「完成，準備發佈」。

    開啟內容編輯器 →

Daily content workflow

導師日常操作：內容、科目與網站瀏覽

完成一次技術設定後，日常工作只需要使用內容編輯器和公開網站。

操作指南 3 部分
  1. 1

    新增或修改內容

    開啟內容編輯器，按左上角 ＋ 新增內容；如要修改現有內容，直接在左邊清單選擇該項。 依次填寫五行分類、內容類型、標題、網址代號 ID、科目、年級、主題、標籤及封面圖。 影片或圖片可按 從電腦選擇 加入；右下角的卡片預覽可用來檢查標題、分類和封面。

    完成後按右上角 完成，準備發佈 →，填寫更新說明，再按 確認並發佈。編輯器會把內容和媒體合併成一次更新，並自動等候及檢查公開網站； 看到「發佈及網站部署完成」後，可直接按 開啟新內容 檢查結果。

    開啟內容編輯器 →
  2. 2

    新增或管理科目

    在內容編輯器按 ＋ 新增內容 或先選擇一項現有內容，然後在 2. 分類與篩選 的科目欄旁按 管理科目。 按 ＋ 新增科目，填寫中文名和英文名，例如「高中數學 / High School Mathematics」。

    可以使用 ↑ ↓ 調整首頁的科目次序，亦可直接改名。新增完成後按「完成」，回到內容表格選擇新科目。 科目改動和內容一樣只會先儲存成草稿，必須完成發佈後才會出現在公開網站。

  3. 3

    瀏覽及檢查網站

    首頁的 五行戰術模組 可按金、木、水、火、土瀏覽內容； 按科目瀏覽 則會開啟指定科目的資料頁。頁面上方可按內容類型、五行、科目、年級、 主題及標籤篩選，亦可切換排序、圖庫或列表檢視。

    使用頁首搜尋框可搜尋標題、科目、主題或標籤。點擊內容卡會進入詳情頁，再使用頁面路徑返回首頁、 五行頁或科目頁。每次發佈後，請檢查科目頁有新卡片、封面可顯示，並開啟詳情頁測試影片、圖片、 文章或互動工具。

    開啟網站 →

IT department / Cursor Agent

IT 部門：為新導師開通發佈權限

IT 管理員可以自行完成以下設定，也可以把導師的公開 GitHub username 交給 Cursor Agent 代為發出邀請。

管理員 4 步
  1. 1

    使用 IT 管理員的 GitHub 帳戶

    登入對 uniplusmathsteam-bot/wuxing-teaching-databank 擁有管理權限的帳戶。每位管理員及導師應使用自己的帳戶，不要共用密碼或權杖。

  2. 2

    邀請導師成為協作者

    請導師提供公開的 GitHub username，不需要 Gmail、密碼或權杖。在 Collaborators 頁面按 Add people，加入該 username 並給予 Write 權限。

    管理 GitHub Collaborators ↗
  3. 3

    或請 Cursor Agent 代為邀請

    在 Cursor 切換到 Agent mode，貼上導師的公開 username，然後要求： 「Invite this teacher to uniplusmathsteam-bot/wuxing-teaching-databank with write access。」 Agent 會使用這部電腦已登入且具有管理權限的 GitHub 帳戶發出邀請，並回報結果。

  4. 4

    由導師接受邀請並建立自己的權杖

    導師接受 GitHub 邀請後，回到本頁完成上面的權杖驗證，再前往內容編輯器。IT 管理員或 Cursor Agent 都不應代收、保存或要求導師交出權杖。

權限分工：IT 管理員或 Cursor Agent 只負責協作者邀請；GitHub 帳戶登入、接受邀請及建立權杖必須由導師本人完成。
